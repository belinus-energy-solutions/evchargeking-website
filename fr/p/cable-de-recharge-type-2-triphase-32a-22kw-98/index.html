Description complète

Ce câble de recharge est équipé à chaque extrémité d'un connecteur de type 2 (1 mâle et 1 femelle). Il est compatible avec les véhicules dotés d'une prise de type 2 (la plupart des modèles européens actuels) et avec les bornes de recharge de type 2, comme celles que l'on trouve généralement dans les stations de recharge publiques en Europe.

Nous n'utilisons pas le câble courant d'origine chinoise, mais un produit européen de haute qualité qui est 20 % plus léger et plus fin, et plus durable ! Les fiches sont dotées de contacts entièrement inoxydables.

La capacité de recharge de ce câble est de 3 x 32 A (5 x 6 mm²), ce qui est suffisant pour tous les types d'infrastructures de recharge et tous les types de véhicules. Vous pouvez recharger à une puissance maximale de 22 kW. Ce câble peut bien sûr également être utilisé pour une recharge à 16 A ou 32 A, en monophasé ou triphasé : vous êtes donc prêt à faire face à des besoins plus importants si nécessaire !

Le câble peut être commandé dans la longueur de votre choix en sélectionnant la longueur souhaitée dans la liste déroulante. Si vous souhaitez une longueur qui ne figure pas dans la liste, vous pouvez Contactez-nous et nous vous proposerons un devis adapté. Si le point de raccordement se trouve de l'autre côté du véhicule, il vous faudra au moins 4 mètres.

Attention : un câble de recharge n'est PAS une rallonge :

Un câble de recharge pour véhicule électrique ne peut être utilisé que pour relier le véhicule à une borne de recharge. Il ne faut PAS utiliser ce câble comme rallonge !

Si vous souhaitez laisser le câble à l'extérieur en permanence, il est fortement recommandé d'installer une prise de type 2, disponible lors du paiement. Vous pouvez également commander un sac de transport pratique à un prix avantageux !
